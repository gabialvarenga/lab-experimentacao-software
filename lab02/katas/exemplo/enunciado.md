# Kata de exemplo — `soma_pares`

Kata "de brinquedo", usado só para validar o fluxo do script de cronometragem
(`scripts/cronometro.py`). **Não entra no experimento.**

Implemente, em `solucao.py`, a função:

```python
def soma_pares(numeros: list[int]) -> int:
    ...
```

que devolve a soma dos números pares da lista. Lista vazia soma `0`. Números
negativos contam normalmente (`-2` é par).
