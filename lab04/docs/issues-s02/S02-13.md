**Contexto e justificativa**

O enunciado exige que o dashboard abra com um único comando descrito no README, ou esteja publicado, com semente fixa. O link do dashboard e do repositório aparecem no topo.

**Objetivo**

Fechar `python -m lab04` (lê o CSV da coleta, roda as simulações e gera o dashboard), documentar no README e publicar a página no GitHub Pages.

**Definições adotadas**

- A coleta pela API fica fora do comando único (precisa de token) e tem comando próprio.
- O README informa o tempo da execução completa.
- O link do Pages e o do Kanban estão no topo do dashboard.

**Interface congelada**

`python -m lab04` (tudo) e `python -m lab04 dashboard` (só a página).

**Procedimento**

1. Implementar o `__main__` com os subcomandos.
2. Rodar em ambiente limpo e anotar o tempo.
3. Configurar a publicação (Actions ou pasta `docs/`) e conferir o link.
4. Atualizar o README.

**Saída esperada**

PR mesclado, página publicada e README com o comando único.

**Casos de borda**

- Execução em máquina sem token (a coleta não pode ser exigida).
- Plotly embutido para abrir sem internet.

**Critérios de aceite**

- [ ] Um comando regenera tudo.
- [ ] Dashboard publicado e link funcionando.
- [ ] Links no topo do dashboard.
- [ ] README atualizado.
- [ ] CI verde.

**Fora do escopo**

Conteúdo dos textos (já nas Issues dos gráficos).
