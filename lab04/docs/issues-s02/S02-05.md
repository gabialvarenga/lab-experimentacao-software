**Contexto e justificativa**

Amostras pequenas também violam os pressupostos assintóticos dos dois testes. O Mann-Whitney usa o p-valor exato quando n é muito pequeno, o que pode deixá-lo conservador por discretização.

**Objetivo**

Rodar as 10.000 repetições para todos os efeitos de C4 (n = 10) e gravar `dados/simulacao/c4.csv`. Opcionalmente, rodar C5 (variâncias e tamanhos desiguais) em `dados/simulacao/c5.csv`.

**Definições adotadas**

- C4: C1 com n = 10 por grupo; registrar se o Mann-Whitney usou o método exato ou assintótico.
- C5 (opcional): com variâncias diferentes, H₀ "médias iguais" deixa de ser "distribuições iguais"; a leitura de erro tipo I muda e precisa ser explicada no dashboard. Só entra se sobrar tempo.

**Interface congelada**

Mesmo formato de CSV da S02-01.

**Procedimento**

1. Rodar a grade para C4.
2. Registrar o método do Mann-Whitney usado.
3. Se couber, rodar C5 e anotar o aviso sobre H₀.
4. Commitar os CSVs.

**Saída esperada**

PR mesclado com o CSV (e C5, se feito).

**Casos de borda**

- Empates em amostras pequenas.
- p-valor exato lento para n maior (não ocorre com n = 10).

**Critérios de aceite**

- [ ] 10.000 repetições por célula em C4.
- [ ] Método do Mann-Whitney registrado.

- [ ] CI verde.
