**Contexto e justificativa**

Os dois testes e as medidas de efeito são usados no exemplo simulado, no G2, na simulação e nos dados reais. Ficam num módulo único e testado.

**Objetivo**

Implementar `lab04/testes.py` com o t de Welch e o Mann-Whitney bicaudais, mais Hedges g, delta de Cliff e razão de medianas.

**Definições adotadas**

- Welch: `scipy.stats.ttest_ind(equal_var=False)`.
- Mann-Whitney: `scipy.stats.mannwhitneyu(alternative="two-sided")`; o método (`exact` ou `asymptotic`) é registrado.
- Hedges g com correção de viés; delta de Cliff em [−1, 1]; razão de medianas = mediana(A) / mediana(B).

**Interface congelada**

`aplicar_testes(a, b) -> dict` com as chaves `welch_t`, `welch_gl`, `welch_p`, `mw_u`, `mw_p`, `mw_metodo`, `hedges_g`, `cliff_delta`, `razao_medianas`.
`aplicar_testes_vetorizado(A, B)` (matrizes, `axis=1`) devolve só os p-valores, para a simulação.

**Procedimento**

1. Escrever as funções.
2. Testar com casos conhecidos (amostras idênticas → g = 0, delta = 0; amostras separadas → p pequeno).
3. Conferir contra `scipy` chamado direto.
4. Garantir que a versão vetorizada dá o mesmo p-valor que a escalar.

**Saída esperada**

PR mesclado com o módulo, os testes e o CI verde.

**Casos de borda**

- Amostras com variância zero.
- Empates (Mann-Whitney).
- Tamanhos diferentes entre grupos.
- Arrays com NaN (erro explícito).

**Critérios de aceite**

- [ ] Duas funções com a interface acima.
- [ ] Testes com casos conhecidos e equivalência escalar × vetorizada.
- [ ] Cobertura do módulo ≥ 80%.
