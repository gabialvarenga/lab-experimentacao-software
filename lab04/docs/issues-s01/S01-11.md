**Contexto e justificativa**

A S01 já deve mostrar G1 e G2 dentro do dashboard. O link do repositório/Projects e o do próprio dashboard ficam no topo.

**Objetivo**

Implementar `lab04/dashboard.py`, que gera um HTML com Plotly e as seções 1 (cenário), 2 (os dados, G1) e 3 (como os testes funcionam, G2), abrindo com um comando descrito no README.

**Definições adotadas**

- Ordem fixa das 7 seções do enunciado; as seções 4 a 7 aparecem como "em construção" até a S02.
- Topo: link do Kanban, link do repositório, link do dashboard (o endereço do GitHub Pages pode ficar como marcador até a S02-13).
- Cada gráfico tem um texto de 2 a 4 frases.

**Interface congelada**

`montar(saida: Path) -> None`, chamada por `python -m lab04 dashboard`. Importa `g1` e `g2` pela assinatura congelada, então pode começar antes dos gráficos chegarem.

**Procedimento**

1. Montar o esqueleto com as 7 seções e os links.
2. Preencher a seção 1 (pergunta, H₀ e H₁, origem e quantidade de dados reais).
3. Integrar G1 e G2 e seus textos.
4. Atualizar o README com o comando.
5. Abrir o HTML do zero, em ambiente limpo, para conferir.

**Saída esperada**

PR mesclado, HTML gerado em `lab04/dashboard/` e abrindo com um comando.

**Casos de borda**

- Gráficos ainda não mesclados (usar marcador).
- Abertura sem internet (Plotly embutido no HTML).

**Critérios de aceite**

- [ ] Seções 1 a 3 com texto.
- [ ] G1 e G2 visíveis.
- [ ] Links no topo.
- [ ] Abre com um comando descrito no README.
- [ ] CI verde.

**Fora do escopo**

Seções 4 a 7 e publicação no GitHub Pages (S02).

**Dependências**

S01-09 e S01-10 (interfaces congeladas permitem começar antes).

**Referências**

Enunciado, seção 4 (dashboard). Prazo: 05/11.
