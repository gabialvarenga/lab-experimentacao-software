**Contexto e justificativa**

A simulação toda depende de uma função que gera duas amostras com efeito conhecido. Pode ser feita com parâmetros provisórios, sem esperar a calibração.

**Objetivo**

Implementar `lab04/gerador.py` com a geração de pares de amostras normais e lognormais, com efeito δ, contaminação por outliers e tamanho variável.

**Definições adotadas**

- Efeito δ: grupo B = grupo A com μ deslocado em δ (na lognormal, razão de medianas = e^δ). Na normal, deslocamento em unidades de desvio-padrão.
- δ = 0 gera os dois grupos da mesma distribuição.
- Outliers: fração `p` das observações multiplicada por `fator`, nos dois grupos.

**Interface congelada**

`gerar_amostra(cenario: dict, delta: float, n: int, rng) -> tuple[ndarray, ndarray]`; `cenario` tem `familia` ("normal" ou "lognormal"), `mu`, `sigma` e, opcionalmente, `contaminacao: {p, fator}`.
Versão em lote: `gerar_lote(cenario, delta, n, n_rep, rng) -> tuple[ndarray, ndarray]` com formato `(n_rep, n)`.

**Procedimento**

1. Escrever as funções.
2. Testar: com `delta = 0` as medianas se aproximam; com `delta > 0` a razão de medianas observada é próxima de e^δ; mesma semente gera os mesmos dados.
3. Testar a contaminação (fração de valores extremos).

**Saída esperada**

PR mesclado com o módulo e os testes.

**Casos de borda**

- `n` pequeno (10).
- `sigma = 0`.
- Contaminação 0 ou 1.
- `rng` repetido entre chamadas.
